# Python Calculator

## About the Project
This is a simple calculator project developed using Python. It performs basic mathematical operations.

## Language Used
- Python

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Checks for division by zero
- Displays the calculation result

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   `python calculator.py`

6. Enter two numbers and an operator when prompted.
