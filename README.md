## ⚙️ How to Run the Projects

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

3. Open the project folder in Visual Studio Code.
4. Open the Python file you want to run.
5. Run the program using the terminal:

   ```bash
   python filename.py
   ```

   Replace `filename.py` with the name of the project you want to execute.

**Example:**

```bash
python guessing.py
```

Some projects may require additional setup or libraries depending on their implementation.
